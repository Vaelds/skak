# Dit næste træk

Et selvstændigt websitekoncept af Anders Vælds til Dansk Skak Union.

## Sider
- index.html: fælles indgang og præsentation af de to målgrupper.
- laer-skak.html: voksne begyndere, niveauvalg, undervisningsforløb og fortsættelse.
- virksomheder.html: firmapakker, dynamisk prisoverblik og print til PDF.
- find-klub.html: søgning i otte regionale indgange og hjælp til første henvendelse.

Ren HTML, CSS og JavaScript. Åbn index.html i en browser, eller rediger mappen i Visual Studio Code. Ingen installation eller bygning kræves. Alle adresser er relative, så siden virker både lokalt og på GitHub Pages.

## Formularer og indhold
Formularerne er tydeligt markerede demonstrationer. Ingen oplysninger sendes eller gemmes på en server. Kladden kan downloades af brugeren. Ingen betaling, tracking eller analyseværktøjer er tilsluttet. Der er ingen database. En rigtig lancering kræver bekræftede tilbud, priser, modtager og en løsning til indsendelse.

Kursuspris 495 kr. og firmapriser 3.500/9.500 kr. er udtrykkeligt konceptpriser, ikke officielle DSU-priser. Ingen opfundne kundeudtalelser eller faste kursusdatoer. Det er forklaret i sidehoved, formularer og Om dette koncept.

## Design og rettigheder
Grafisk reference og illustrationer genbrugt fra https://vaelds.github.io/skak/ efter brugerens anvisning. Sort/pink farveunivers og Oswald/Montserrat-skrifter. Kilder til organisationsstruktur: https://organisation.skak.dk/medlemskab-i-dansk-skak-union/ og https://organisation.skak.dk/. Google Fonts er gemt lokalt, så siden ikke kræver et kald til en fonttjeneste. Ikon og logo genbruges fra det oprindelige projekt.

## Offentliggørelse
Denne mappe tilføjes separat i Vaelds/skak uden at ændre den eksisterende hjemmeside. GitHub Pages-adressen er https://vaelds.github.io/skak/skakfaellesskab/.
